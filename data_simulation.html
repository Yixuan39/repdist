Simulated test dataset: one function across remote homologs

GrpE (COG0576) spiked into group A, one 30% cluster per sample

Design. 20 samples, 10 in group A and 10 in group B. All samples share 100 background proteins drawn at random from other COGs. Each group-A sample also carries one GrpE protein (COG0576) of its own, and the 10 GrpE proteins come from 10 different MMseqs2 30% clusters (Steinegger and Söding 2017). So group A is enriched for one function, while no sequence family is enriched in more than one sample. The FASTA therefore holds 110 proteins (100 + 10); an A sample has 101, a B sample 100.

Parameter Value

Samples 10 A + 10 B

The COG 2024 release (Galperin et al. 2025): protein-to-COG assignments, the protein sequences of its 2,296 genomes, COG names and functional categories. About 2.2 GB, downloaded once into data/cog/ and checked against the release’s MD5 sums.

2. One-label pool

A protein qualifies if it has exactly one COG, every assignment row for it is membership class 0 (the COG covers most of the protein and most of the COG profile, so the label is full-length), and it is 50-1000 residues long.

4. GrpE: one protein from each of 10 different 30% clusters

Every qualifying GrpE protein is clustered with MMseqs2 at 30% identity and 80% coverage of both sequences (-s 7.5, the settings of the other simulations). Clusters are visited in random order and one random member is taken from each, but only if it has no alignment of \(\ge\) 30% identity over 70% of both proteins with a GrpE protein already taken. Greedy clustering depends on which sequences are present, so this pairwise rule is what keeps the 10 in 10 clusters when clustered with the background; the margin (70%, not 80%) is there because easy-search and easy-cluster align slightly differently (one pair at 48% identity covered 76-79% in the search but was clustered together).

mmseqs_cluster <- function(seqs) {
    tmp <- tempfile("mm")
    dir.create(tmp)
    f <- file.path(tmp, "x.fasta")
    Biostrings::writeXStringSet(Biostrings::AAStringSet(seqs), f)
    stopifnot(system2("mmseqs", c("easy-cluster", f, file.path(tmp, "c"), file.path(tmp, "w"),
        "--min-seq-id", 0.3, "-c", 0.8, "--cov-mode", 0, "--cluster-mode", 0, "-s", 7.5),
        stdout = FALSE, stderr = FALSE) == 0L)
    m <- read.delim(file.path(tmp, "c_cluster.tsv"), header = FALSE)
    unlink(tmp, recursive = TRUE)
    setNames(m$V1, m$V2)[names(seqs)]
}
mmseqs_search <- function(seqs) {
    tmp <- tempfile("mm")
    dir.create(tmp)
    f <- file.path(tmp, "x.fasta")
    Biostrings::writeXStringSet(Biostrings::AAStringSet(seqs), f)
    stopifnot(system2("mmseqs", c("easy-search", f, f, file.path(tmp, "h.m8"),
        file.path(tmp, "w"), "-s", 7.5, "-e", "1e-3", "--max-seqs", 10000,
        "--format-output", "query,target,fident,qcov,tcov,evalue"),
        stdout = FALSE, stderr = FALSE) == 0L)
    h <- read.delim(file.path(tmp, "h.m8"), header = FALSE,
        col.names = c("query", "target", "fident", "qcov", "tcov", "evalue"))
    unlink(tmp, recursive = TRUE)
    h[h$query != h$target, ]
}

5. Background: 100 random proteins

Background candidates with an MMseqs2 hit to any of the 10 GrpE proteins (E \(\le\) 10-3 and 80% coverage of both) are dropped, so no background protein is a close homolog of the treatment; the first 100 remaining, in the random order of the draw, are kept.

bg <- cand[cand$cog != treatment_cog, ]
bg <- bg[match(bg_cand$protein, bg$protein, nomatch = 0L), ]

leak <- unique(c(h$query[h$target %in% treat$protein], h$target[h$query %in% treat$protein]))
leak <- intersect(leak, bg$protein)
bg <- head(bg[!bg$protein %in% leak, ], n_background)

8. Count table

A negative-binomial model, as in the other simulations. Background abundances \(\pi\) are log-normal and shared by all samples; sample \(i\) has size factor \(s_i \sim \mathrm{LogNormal}(0, 0.25)\) and protein \(j\) has dispersion \(\phi_{ij} = (0.1 + 1/\mu_{ij})\, e_j\), \(e_j \sim \mathrm{LogNormal}(0, 0.5)\). Group-A sample \(i\) puts a share \(\rho = 5\%\) of its abundance on its own GrpE protein and \(1 - \rho\) on the background; group B and every other GrpE protein get 0. The counts are drawn with seed 1.

samples <- data.frame(sample = c(sprintf("A%02d", seq_len(n_per_group)),
    sprintf("B%02d", seq_len(n_per_group))), group = rep(c("A", "B"), each = n_per_group))
samples$grpe_protein <- treat$protein[match(samples$sample, treat$enriched_in)]
write.table(samples, file.path(out_dir, "samples.tsv"), sep = "\t", quote = FALSE,
    row.names = FALSE, na = "")
set.seed(20261112L)
pi <- setNames(rlnorm(nrow(bg)), bg$protein)
pi <- pi / sum(pi)
s <- rlnorm(nrow(samples), 0, 0.25)
e <- setNames(rlnorm(nrow(u), 0, 0.5), u$protein)
p <- matrix(0, nrow(samples), nrow(u), dimnames = list(samples$sample, u$protein))
p[, bg$protein] <- matrix(pi, nrow(samples), nrow(bg), byrow = TRUE)
a <- samples$group == "A"
p[a, ] <- (1 - rho) * p[a, ]
p[cbind(which(a), match(samples$grpe_protein[a], u$protein))] <- rho
mu <- s * depth * p
phi <- (0.1 + 1 / mu) * rep(e, each = nrow(samples))
set.seed(1)
counts <- matrix(rnbinom(length(mu), mu = mu, size = 1 / phi), nrow(mu),
    dimnames = dimnames(mu))
counts[mu == 0] <- 0L # rnbinom gives NaN at mu = 0, size = 0
storage.mode(counts) <- "integer"
write.table(data.frame(sample = rownames(counts), counts, check.names = FALSE),
    file.path(out_dir, "counts.tsv"), sep = "\t", quote = FALSE, row.names = FALSE)
share <- rowSums(counts[a, treat$protein]) / rowSums(counts[a, ])
c(median_depth = median(rowSums(counts)), GrpE_share_in_A_median = median(share),
    GrpE_share_in_A_min = min(share), GrpE_share_in_A_max = max(share),
    GrpE_counts_in_B = sum(counts[!a, treat$protein]))
