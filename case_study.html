Case study

Mouse gut metaproteomes across a dietary-protein series

This page runs the repdist workflow on a published metaproteome: beta diversity with MMD (sample_mmd(), the maximum mean discrepancy under a Gaussian kernel on the protein embeddings), the representation space, MCL bins, and bin-level differential abundance.

library(repdist)
library(ggplot2)
library(vegan)

Study and comparison

Blakeley-Ruiz et al. (Blakeley-Ruiz et al. 2025) fed twelve mice, four cages of three, a series of defined diets, one week each, and measured faecal metaproteomes by spectral counting (PRIDE PXD041586). The males (C1, C3) and females (C2, C4) came from different rooms at the Jackson Laboratory, so sex also marks two starting microbiomes, which the paper calls mouse groups.

The input sequences are already sequence-reduced. The microbial protein catalog comes from metagenome-assembled genomes annotated with PROKKA; unbinned genes were added only if no binned gene matched them at 90% identity (CD-HIT-2D), and the host and diet reference proteomes were clustered at 95% identity. Every reported protein also has at least one protein-unique peptide. Near-identical proteins are therefore rare in the table (see sequence identity of graph edges): the relatedness that MMD and the bins add beyond protein identity is mostly remote homology.

Beta diversity compares the six dietary protein sources (soy, casein, rice, yeast, pea and egg) across the series. The bins and differential abundance compare two diets of the same protein amount, 20% yeast protein (Yeast) against 20% casein (Casein), casein being the reference protein of the series, in the 11 mice sampled on both. Diets were fed in a fixed order, one week each, so protein source is partly confounded with feeding week.

Data. The input file is curated/diet_series.rds (42 MB), in the repository’s curated/ folder on the gh-pages branch. To run the code on this page, save it in a curated/ folder next to your working directory.

It is not part of the package; the package’s inst/extdata/metaproteomics.* files, used in its help-page examples, are a 100-protein cut of the same study.

The curated object was built by data-raw/diet_series.R from the paper’s supplementary Data Set 1 (PSM counts and sequences) and Data Set 6 (annotation): every microbial protein with at least one PSM in any sample, its species group and GTDB lineage, the study’s curated function, KEGG orthology (KO) assignments and CAZy families, and a TM-Vec embedding computed with embed_proteins().

Protein length. Proteins longer than MAX_AA = 1500 residues were removed before embedding: 424 of 30103 proteins, carrying 3.2% of the PSMs. This is an analysis choice, not a package limit: embed_proteins() embeds sequences of any length, but the TM-Vec head was trained on chains of up to 1000 residues, so predicted TM-scores for much longer chains are extrapolations.

Beta diversity across protein sources

The samples are named by diet token (percentage and protein source). The T0 baseline on standard chow is left out. The 40% soy and 40% casein weeks count under their protein source, and so does the CTL re-feeding at the end of the series: 20% soy in cages C1 and C2, 20% casein in C3 and C4.

PSM totals differ between samples, and sampling depth changes which proteins are observed. For this case study, both distances use the same counts rarefied to the smallest sample, followed by relative-abundance normalisation. Rarefaction standardises the number of observed PSMs but discards counts and adds sampling variability; it is an analysis choice, not a requirement of MMD. It does not recover undetected proteins or remove all effects of the observation process.

range(rowSums(counts[rownames(md), ]))
#> [1]  5441 39491
set.seed(1)
rarefied <- rrarefy(counts[rownames(md), ], min(rowSums(counts[rownames(md), ])))
rarefied <- rarefied[, colSums(rarefied) > 0]
relative <- rarefied / rowSums(rarefied)
D <- list(
    `Bray-Curtis (protein)` = vegdist(relative, "bray"), # shared accessions
    MMD = sample_mmd(relative, proteins) # distance between embeddings
)

PERMANOVA (Anderson 2001) tests protein source after protein amount, cage and week, and PERMDISP (Anderson 2006) tests for unequal spread between sources; both use 999 permutations restricted to within mouse. Cage nests sex.

The table reports sequential R² and the p values returned by adonis2(). Cage R² is reported descriptively. Because every mouse stays in one cage, within-mouse permutations preserve cage membership; the printed cage p value is not interpreted as a test of a between-cage effect. The numeric week term adjusts for a linear time trend only. Diets were fed in a fixed order, so the diet association cannot be separated from arbitrary changes over time.

perm <- permute::how(blocks = md$subject, nperm = 999)
permanova <- lapply(D, function(Dk) {
    set.seed(1)
    as.data.frame(adonis2(Dk ~ dose + cage + week + diet, data = md,
        by = "terms", permutations = perm))
})
permdisp <- vapply(D, function(Dk) {
    set.seed(1)
    permutest(betadisper(Dk, md$diet), permutations = perm)$tab[1, "Pr(>F)"]
}, numeric(1))

The MMD plot comes from plot_pcoa(), which leaves out the two most abundant protein regions, named in its subtitle, before the PCoA. Their share varies with things other than diet, so the plot is less crowded without them. This is for display only: the PERMANOVA above uses the full distance. Each source is outlined by its convex hull.

plot_pcoa(relative, proteins, md$diet, drop = 2) + ggplot2::ggtitle("MMD")

Both distances detect protein source. MMD attributes more of the variation to it than protein-level Bray-Curtis does (R² 0.322 against 0.251), and only Bray-Curtis also shows unequal spread between sources (PERMDISP p 0.001 against 0.554), so the MMD separation is mainly a shift in location.

The sequential R² assigned to cage is smaller under MMD (R² 0.154 against 0.191). This is a descriptive comparison of the two distance spaces. In the ordination, the first Bray-Curtis axis separates C1 and C3 from C2 and C4, while the first MMD axis separates yeast and egg from the other sources.

To see what separates the mouse groups, the next chunk sets aside proteins seen in only one group and finds each one’s nearest protein in the other group by TM-Vec similarity.

group <- ifelse(md$cage %in% c("C1", "C3"), "A", "B")

mine <- ifelse(psm["B", ] == 0, "A", ifelse(psm["A", ] == 0, "B", "shared"))
group_private <- c(A = sum(psm["A", mine == "A"]) / sum(psm["A", ]),
    B = sum(psm["B", mine == "B"]) / sum(psm["B", ]))
# nearest protein seen in the other group, for a PSM-weighted sample of 300
# group-private proteins per group
Z <- S4Vectors::mcols(proteins)$embedding
Z <- Z / sqrt(rowSums(Z^2))
seqs <- proteins
S4Vectors::mcols(seqs) <- NULL
set.seed(1)
nn <- do.call(rbind, lapply(c("A", "B"), function(g) {
    own <- which(mine == g)
    other <- which(psm[setdiff(c("A", "B"), g), ] > 0)
    i <- sample(own, 300, prob = psm[g, own])
    cs <- Z[i, ] %*% t(Z[other, ])
    j <- other[max.col(cs, "first")]

        substitutionMatrix = "BLOSUM62", type = "local",
        gapOpening = 11, gapExtension = 1)
    data.frame(group = g, tm = apply(cs, 1, max),
        identity = pwalign::pid(aln, type = "PID1"))
}))

The two mouse groups, A (C1, C3) and B (C2, C4), carry different variants of the same protein families. Proteins seen in one group only hold 24% of A’s and 12% of B’s PSMs, and their nearest protein in the other group is a same-fold homolog (median predicted TM-score 0.97) at under 90% identity in 93% of cases. Bray-Curtis counts these as different proteins and MMD counts them as close.

Representation space

plot_tsne() maps the contrast’s proteins by cosine distance (one minus the predicted TM-score), coloured by the study’s manually curated broad function; proteins without one are grey. The map shows neighbourhoods in representation space; it is not evidence of function, and t-SNE does not preserve distances between groups.

Differential abundance

Raw (unrarefied) protein counts are summed to bins with bin_glom(). Each sample’s bin counts, plus a pseudo count of 1, are put on the centred log-ratio (CLR) scale (Aitchison 1982), and each bin seen in at least 10% of samples is tested with a linear model ~ subject + diet, which pairs the two samples of each mouse. LFC is the log2 fold change of Yeast over Casein; q is the Benjamini-Hochberg adjusted p-value.

bin_counts <- bin_glom(counts, bins) # sum protein counts within each bin
clr <- log2(bin_counts + 1)
clr <- clr - rowMeans(clr) # centred log-ratio within each sample
seen <- colMeans(bin_counts > 0) >= 0.1
fit <- t(apply(clr[, seen], 2, function(y) {
    summary(lm(y ~ subject + diet, data = samples))$coefficients[
        "dietYeast", c("Estimate", "Pr(>|t|)")]
}))
res <- data.frame(LFC = fit[, 1], p = fit[, 2],
    q = p.adjust(fit[, 2], "BH"), mean_clr = colMeans(clr[, seen]),
    row.names = rownames(fit))
c(tested = nrow(res), up_yeast = sum(res$q < 0.05 & res$LFC > 0),
    up_casein = sum(res$q < 0.05 & res$LFC < 0))
#>    tested  up_yeast up_casein 
#>      1246       354       311

Each bin’s annotation summarises its members. A label shared by every annotated member is shown with its count (3/4 means three of four members carry it, the fourth is unannotated); bins whose annotated members disagree are marked mixed with the number of distinct labels and the most frequent one.

summarise_labels <- function(v) {
    n <- length(v)
    v <- v[!is.na(v)]
    if (!length(v)) return("-")
    tab <- sort(table(v), decreasing = TRUE)
    top <- sprintf("%s (%d/%d)", strtrim(names(tab)[1], 40), tab[[1]], n)
    if (length(tab) == 1L) top else
        sprintf("mixed, %d: %s", length(tab), top)
}
bin_table <- function(ids) {
    data.frame(
        bin = ids,
        proteins = sizes[ids],
        taxon = vapply(bins$clusters[ids],
            function(m) summarise_labels(ann[m, "taxon"]), ""),
        `function` = vapply(bins$clusters[ids],
            function(m) summarise_labels(ann[m, "consensus_annotation"]), ""),
        KO = vapply(bins$clusters[ids],
            function(m) summarise_labels(ann[m, "ko"]), ""),
        LFC = round(res[ids, "LFC"], 2),
        p = formatC(res[ids, "p"], format = "e", digits = 1),
        q = formatC(res[ids, "q"], format = "e", digits = 1),
        check.names = FALSE, row.names = NULL
    )
}
sig <- rownames(res)[res$q < 0.05]
sig <- sig[order(res[sig, "p"])]
up_yeast <- sig[res[sig, "LFC"] > 0]
up_casein <- sig[res[sig, "LFC"] < 0]

Inside a bin

plot_bin_similarity() shows the edges among one bin’s members. A coloured cell is an edge of the graph: the pair’s alignment passed the E-value gate, and the colour is the edge’s weight, its predicted TM-score. A grey cell is not an edge (weight 0 in S): its alignment failed the gate, and the pair is in the bin only through shared neighbours. MCL clusters along the edges. Shown are the most significant bin with 4 to 30 members in each direction, with a count of their member pairs.

pick <- function(ids) ids[sizes[ids] >= 4 & sizes[ids] <= 30][1]
shown <- c(Yeast = pick(up_yeast), Casein = pick(up_casein))
pair_types <- function(bin) {
    m <- bins$clusters[[bin]]
    E <- S[m, m] > 0
    up <- upper.tri(E)
    c(pairs = sum(up), edges = sum(E[up]), not_edges = sum(!E[up]))
}

Notes
