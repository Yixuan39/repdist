repdist

Comparing proteins and metaproteomes in protein representation space

Identity-based measures compare proteins only by accession. Protein-level Bray-Curtis, for example, treats two different accessions as unrelated even when they share fold and function. Two metaproteomes can therefore hold different accessions yet carry similar structural or functional protein repertoires.

repdist uses protein representations (embeddings from a protein language model; by default TM-Vec, whose cosine similarity is a predicted TM-score) for two related tasks:

A. Comparing samples. Each sample is an abundance-weighted distribution of its proteins in representation space. sample_mmd() compares two such distributions by the maximum mean discrepancy (MMD) under a Gaussian (RBF) kernel, so different but closely related proteins partly match.

B. Grouping proteins. protein_similarity() turns pairwise similarities into a weighted graph, keeping only pairs that pass a similarity threshold and an alignment-coverage threshold. bin_proteins() partitions the graph by Markov clustering (MCL), and bin_glom() sums protein counts within each bin for count-based analyses such as DESeq2.

Documentation

Reference: what each function computes and how to call it: embeddings, the MMD distance, the similarity graph and MCL bins, and the QC plots.

Simulation: two benchmarks with known truth. A controlled positive benchmark on CATH FunFam domains, where one group’s enriched proteins share a hidden family and no accession; and sequence-disjoint contrasts between enzyme classes (EC3) of experimentally characterised Swiss-Prot enzymes, against Bray-Curtis on MCL bins, MMseqs2 bins and proteins. Then how completely the MCL bins recover enzyme classes.

MCL parameters: how min_sim, min_coverage and the MCL inflation change the bins, scored against the simulation’s enzyme labels.

Case study: a worked metaproteomics analysis of a 20% yeast vs 20% casein diet comparison in mice: beta diversity, the representation space, MCL bins and bin-level differential abundance with DESeq2.

Installation

repdist is an R package (R >= 4.5). Install the development version from GitHub:

if (!requireNamespace("remotes", quietly = TRUE))
    install.packages("remotes")
remotes::install_github("Yixuan39/repdist")

embed_proteins() runs its models in a Python environment that repdist creates and manages itself through basilisk; no manual Python setup is needed. Model weights are downloaded on first use.

library(repdist)
x <- embed_proteins("proteins.fasta")      # default model: "tmvec"

D <- sample_mmd(counts, x)                 # samples x samples dist
vegan::adonis2(D ~ group, data = metadata)

S <- protein_similarity(x)                 # weighted similarity graph
bins <- bin_proteins(S)                    # MCL bins
binned <- bin_glom(counts, bins)           # samples x bins counts

counts has samples in rows and proteins in columns, named as in x.
